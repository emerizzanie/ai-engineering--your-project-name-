# Part B Reflection

The component with the most potential failure points is the interaction
between the user prompt, the moderation filters, the retrieval system
and the AI model. For example, the system may misunderstand a prompt,
retrieve incomplete or outdated information, or generate an incorrect
answer. The output safety filter may also block a harmless question by
mistake.

This shows that AI Engineering effort should focus on making answers
accurate, safe and reliable. The system should check the information it
retrieves, explain uncertainty when needed and be tested for different
types of prompts. Monitoring response time and user feedback can also
help identify problems and improve the system.
